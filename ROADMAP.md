# Ideas

Things that would fit Blink, roughly in the order I'd do them. The rule: keep it fast, keyboard-first and free of extra permissions.

- **Mouse follows focus.** When you switch apps with ⌘Tab, the Dock or Spotlight and the new window is on another screen, the cursor comes along. Opt-in.
- **Blink back.** One shortcut that jumps back to where the cursor was before the last blink.
- **Window switcher.** Like ⌥Tab, but stepping through windows instead of screens, with the cursor following. The hold-to-switch mechanics are already there.
- **Directional window focus.** Jump to the nearest window left/right/up/down, across screens.
- **App shortcuts.** One key per app that focuses its window and puts the cursor on it.
- **Homebrew cask**, so installing is one command.
